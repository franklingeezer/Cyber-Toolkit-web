# 🛡️ Cyber Toolkit v3

A modern cybersecurity-inspired web toolkit with an immersive hacker-style interface, interactive terminal, and useful security utilities—all built using HTML, CSS, and JavaScript.

---

## ✨ Features

- 🚀 Animated boot sequence
- 💻 Interactive full-screen terminal
- 🌌 Matrix rain background
- 📊 Security dashboard
- 🔐 Password generator
- 📈 Password strength checker
- 🔒 Text encryption & decryption
- 🔑 Hash generation utilities
- 🌐 Network utility tools
- ⚡ Responsive design
- 🎨 Modern cyber-themed UI

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/franklingeezer/Cyber-Toolkit-web.git
```

### Navigate to the project

```bash
cd Cyber-Toolkit-web
```

### Run the project

Simply open `index.html` in your browser, or use **VS Code Live Server** for the best experience.
